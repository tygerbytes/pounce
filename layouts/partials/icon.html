{{- /* Renders an inline SVG icon from data/icons.toml. Accepts either a bare icon name, or a dict with "name" and an optional "class" (e.g. "icon-lg") for sizing: {{ partial "icon" "home" }} {{ partial "icon" (dict "name" "arrow-up" "class" "icon-lg") }} Icons are decorative here -- every call site pairs them with visible text or an aria-label -- so they are hidden from assistive tech. The SVG inherits colour via fill="currentColor" and scales with font-size, which is what the old Font Awesome elements did. Emits no surrounding whitespace: it is used inline, mid-sentence. */ -}} {{- $name := . -}} {{- $class := "" -}} {{- if reflect.IsMap . -}} {{- $name = .name -}} {{- $class = .class | default "" -}} {{- end -}} {{- with index hugo.Data.icons $name -}} {{- else -}} {{- errorf "partial icon: no icon named %q in data/icons.toml" $name -}} {{- end -}}
